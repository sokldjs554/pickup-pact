Pickup Pact는 카페 주문 화면을 다시 만드는 프로젝트가 아닙니다. 주문·결제·정산·적립 서비스가 분리된 환경에서 메시지가 늦거나 중복될 때 서로 다른 상태를 다시 맞추는 백엔드입니다.

고객 취소→메시지 지연/중복→정산·적립 오류→원인 판정→보상/상태 복구

모든 주문·매장·결제 데이터는 합성 데이터입니다. 실제 결제사나 실제 점주 계정과 연결하지 않습니다. 공개 데모는 프로젝트의 실제 reconciliation engine을 사용해 시나리오를 판정합니다.
